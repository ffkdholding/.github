Discussions Roadmap
1
Levantamento de Requisitos
Em andamento
Entender o que o produto precisa fazer antes de qualquer linha de código. O time responde perguntas sobre o negócio via GitHub Discussions com polls e comentários. Cada resposta vai definir o que entra no MVP e o que fica para versões futuras.
Entregas desta fase
💬
GitHub Discussions
45 perguntas sobre o produto abertas para votação do time
Votando
📊
Dashboard de status
Acompanhamento visual do progresso das votações
Feito
📋
Decisões documentadas (ADRs)
Cada votação fechada vira um registro permanente de decisão
Pendente
→ Ver status das Discussions
2
User Stories
Próxima fase
Com os requisitos definidos, descrevemos o produto do ponto de vista de quem vai usar. Para cada perfil (Gestor de Frota, Motorista, Financeiro) escrevemos as histórias: "Como gestor, quero ver o TCO do mês para tomar decisões de renovação da frota." Essas histórias guiam o design e o desenvolvimento.
Entregas desta fase
👤
Personas
Perfis detalhados de cada tipo de usuário da plataforma
Pendente
📝
User Stories do MVP
Lista priorizada do que cada perfil precisa fazer na plataforma
Pendente
🗺️
Fluxos de uso
Passo a passo de como cada perfil navega pela plataforma
Pendente
3
Design das Telas
Próxima fase
Transformar as user stories em telas reais. Sem Figma — as telas são geradas diretamente em código (HTML/React) e validadas no browser pelo time. O resultado é o guia visual para o desenvolvimento do frontend.
Entregas desta fase
🖥️
Telas do portal web
Dashboard, frota, veículos, TCO, relatórios, configurações
Pendente
📱
Telas do app mobile
Consultas rápidas, alertas e abastecimento em campo
Pendente
